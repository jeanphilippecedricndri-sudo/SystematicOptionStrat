# Data

**The real market data is not included in this repository.** To obtain it, please contact me by opening an issue on this repository.

| File | Included | Description |
|---|---|---|
| `spy_simulated_2020_2022.csv` | yes | Synthetic SPY option chain generated by `src/generate_simulated_data.py`. Runs every notebook offline. |
| `spy_2020_2022.csv` | no, on request | Real SPY end-of-day option chains, 1.3 GB |
| `qqq_2020_2022.csv` | no, on request | Real QQQ end-of-day option chains, 0.6 GB |
| `aapl_2016_2020.csv` | no, on request | Real AAPL end-of-day option chains, 0.4 GB |

Once received, place the files here under the names above. Bracketed column headers (`[QUOTE_DATE]`, ...) are stripped automatically by `src/data_loader.py`.
